# CIFAKE Dataset Documentation

## 1. Overview & Dataset Name
- **Dataset Name**: CIFAKE — Real and AI-Generated Synthetic Images
- **Official Source**: [Kaggle Dataset: CIFAKE (birdy654)](https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images)
- **Reference**: Bird, J.J., & Lotfi, A. (2023). *CIFAKE: Image Classification and Explainable Identification of AI-Generated Synthetic Images*. IEEE Access.

## 2. Class Descriptions
The CIFAKE dataset is a balanced benchmark containing 120,000 images (32x32 pixels originally, resized for deep CNN architectures) across two binary classes:
1. **REAL (Label: 1)**:
   - 60,000 authentic images sourced from the classical CIFAR-10 dataset across 10 categories (airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck).
2. **FAKE (Label: 0)**:
   - 60,000 synthetic images generated by Stable Diffusion v1.4 conditioned on the same 10 CIFAR-10 class prompts.

### Split Distribution:
- **Train split**: 100,000 images total (50,000 REAL, 50,000 FAKE)
- **Test split**: 20,000 images total (10,000 REAL, 10,000 FAKE)

## 3. Expected Folder Structure
Once downloaded and extracted, the directory must have the following exact layout:

```text
CIFAKE/
├── train/
│   ├── FAKE/     (50,000 .jpg images)
│   └── REAL/     (50,000 .jpg images)
└── test/
    ├── FAKE/     (10,000 .jpg images)
    └── REAL/     (10,000 .jpg images)
```

## 4. Download and Setup Instructions

### Option A: Manual Download (Recommended for Beginners)
1. Visit the Kaggle dataset page: [CIFAKE on Kaggle](https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images).
2. Log in to your Kaggle account and click **Download (203 MB)**.
3. Save the downloaded archive `archive.zip` (or `cifake-real-and-ai-generated-synthetic-images.zip`).
4. Extract the zip file into your local project `data/` directory or an accessible storage directory.
   - For example:
     - Windows PowerShell:
       ```powershell
       Expand-Archive -Path "path\to\archive.zip" -DestinationPath "data\CIFAKE"
       ```
     - Linux / macOS / Colab:
       ```bash
       unzip archive.zip -d data/CIFAKE
       ```
5. Confirm that `data/CIFAKE/train/FAKE`, `data/CIFAKE/train/REAL`, `data/CIFAKE/test/FAKE`, and `data/CIFAKE/test/REAL` directories exist.

### Option B: Kaggle API CLI Download (Do NOT hardcode credentials)
If you use the Kaggle CLI:
1. Ensure your `kaggle.json` token is placed securely in `~/.kaggle/kaggle.json` (Linux/Mac) or `%USERPROFILE%\.kaggle\kaggle.json` (Windows).
2. Download via terminal:
   ```bash
   kaggle datasets download -d birdy654/cifake-real-and-ai-generated-synthetic-images -p data/
   ```
3. Extract:
   ```bash
   unzip data/cifake-real-and-ai-generated-synthetic-images.zip -d data/CIFAKE
   ```

## 5. Configuring the Dataset Path
The project scripts accept `--data_dir` to point to the root of the extracted dataset:

```bash
# Example training command pointing to the extracted data
python main.py --data_dir data/CIFAKE --epochs 5 --batch_size 32
```

In Google Colab, mount Google Drive or download directly, and provide the path:
```python
DATA_DIR = "/content/drive/MyDrive/CIFAKE"  # or "/content/CIFAKE"
```

## 6. Important Notes & Integrity
- **Do not commit raw dataset images to GitHub**: The dataset is over 200 MB compressed and contains 120,000 image files. `.gitignore` is configured to exclude `CIFAKE/` and `data/train/` to protect repository health and adhere to GitHub storage limits.
- **Corrupted / Unsupported files**: The dataset loading pipeline in `src/dataset.py` includes validation logic to check file extensions and verify image decodability.
